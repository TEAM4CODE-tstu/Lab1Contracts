# Lab1Contracts

# Лабораторная работа №1 — «Контракты в интерфейсе»

## Что это?
Данное приложение представляет собой интерактивную настольную систему для демонстрации концепции **контрактного программирования** (Design by Contract) в пользовательских интерфейсах. Проект наглядно показывает, как формулируются, проверяются и визуализируются спецификации операций в виде предусловий (**Pre**) и постусловий (**Post**).

## Описание
В качестве сквозного сюжета для бизнес-логики выбран модуль **«Сортировка и агрегация»**. Приложение содержит три взаимосвязанные операции:
1. **Поиск минимума и максимума** в массиве чисел.
2. **Сортировка массива** (по неубыванию).
3. **Подсчет суммы элементов** числовой последовательности.

Каждая операция строго контролируется контрактами. Перед выполнением алгоритма происходит проверка предусловий, а после завершения — верификация постусловий. Результаты проверок мгновенно отображаются пользователю в виде цветовых индикаторов (зеленый/красный) с понятным текстовым сопровождением.

## Установка
1. Склонируйте репозиторий вашей команды на локальный компьютер:
   ```bash
   git clone https://github.com
   ```
2. Перейдите в корневую папку проекта:
   ```bash
   cd Lab1Contracts
   ```
3. Откройте файл решения `Lab1.slnx` (или `Lab1.sln`) в Visual Studio.
4. Восстановите пакеты NuGet и соберите проект (`Ctrl + Shift + B`).

## Как пользоваться приложением
1. **Выбор операции:** В левой панели меню выберите интересующий алгоритм (например, «Сортировка массива»).
2. **Ввод данных:** В правой карточке операции введите массив чисел через пробел, запятую или точку с запятой.
3. **Контроль Pre-условий:** Обратите внимание на круглый индикатор «Предусловие». Если ввод некорректен (например, поле пустое), индикатор загорится красным. Если все требования соблюдены — зеленым.
4. **Выполнение:** Нажмите кнопку **«Выполнить»**. Алгоритм обработает данные, выведет результат в поле ниже, а индикатор **«Постусловие»** подтвердит математическую корректность выполнения операции.
5. **Просмотр контракта:** Нажмите кнопку **«Показать контракт»**, чтобы открыть модальное окно. Там подробно расписаны формальные правила Pre/Post условий, возможные исключения и граничные примеры.
6. **Выход:** Для безопасного и корректного закрытия приложения используйте встроенную кнопку **«Выход»** внизу левой панели меню (системный крестик окна заблокирован в целях демонстрации управления жизненным циклом программы).
